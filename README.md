| 你做的操作 | 实际含义 |
|---|---|
| Fork | 把别人的仓库整体复制一份到你名下,你随便改,动不到原版 |
| Edit + Commit | 在**你的副本**里保存一次改动,commit 就是"存档点" |
| Open pull request | 向原作者申请:"我这份副本里有个改动,请你们收下" |
| Merge | 原作者接受了,把你的改动合并进原仓库 |
